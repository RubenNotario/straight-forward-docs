# SF Steam Online Sessions - Overview

**SF Steam Online Sessions** is a lightweight, high-level Unreal Engine plugin designed to wrap Unreal's Online Subsystem (OSS) and Steam Online Subsystem into a clean, easy-to-use GameInstance Subsystem (`USFOSMultiplayerSessionsSubsystem`).

---

## 🎯 Key Features

- 🌐 **Seamless Multiplayer Hosting & Joining:** Easily host public or private sessions and join games via Blueprint nodes or C++.
- 👥 **Steam Friends & Invites Integration:** Fetch active Steam friend games, send invites, and open native Steam invite UI overlay.
- 🖼️ **Steam Player Avatars:** Fetch player Steam profile avatars directly into UMG Texture2D widgets for custom lobby menus.
- 🔄 **Async Event Delegates:** Asynchronous callbacks for creation, discovery, joining, and destruction of game sessions.
- ✈️ **Seamless Server Travel:** Built-in helper to update and switch server maps for all connected clients.

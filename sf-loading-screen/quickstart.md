# SF Loading Screen - Quickstart Example

---

1. **Project Settings ➔ Plugins ➔ Straight Forward Loading Screen**: set `DefaultLoadingTitle`, add 3-5 `LoadingTips` and a background image.
2. Before travelling to a boss arena: `Set Next Loading Tip ("Dodge the slam attack!")` ➔ `Open Level`.
3. While connecting to a server: `Play Loading Screen` ➔ (connection done) ➔ `Stop Loading Screen`.

> 💡 Launch `Levels/HowToUse` as **Standalone Game** to see it.

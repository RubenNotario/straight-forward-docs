# Welcome to Straight Forward Solid Systems 🚀

Welcome to the official documentation for **Straight Forward Solid Systems** — a suite of modular, robust, and reusable plugins for **Unreal Engine**.

---

## 💡 Philosophy

Straight Forward Solid Systems is built on a core principle: **solving common game development challenges with maximum efficiency and minimal complexity.**

- 🎯 **Focused & Lightweight:** Each plugin does one job and does it exceptionally well.
- 🔌 **Plug & Play:** Designed for rapid integration into any Unreal Engine C++ or Blueprint project.
- 🛠️ **Production Ready:** Clean C++ code with full Blueprint exposure and zero bloat.

---

## 📦 Available Plugins

| Plugin | Category | Key Feature |
| :--- | :--- | :--- |
| **SF Steam Online Sessions** | Multiplayer | Complete Steam & Session management (Host, Find, Join, Invites, Avatars). |
| **SF Fades** | UI / FX | Asynchronous screen color & material transitions across level loads. |
| **SF Timers** | Gameplay / Systems | World-based chronometer & countdown timer subsystem with built-in string formatting. |
| **SF Toasts** | UI / Notifications | Floating notification toasts & modal popups with automatic layout stack. |

# SF Virtual Cursor - Quickstart Example

---

1. Inventory opened: `Enable Virtual Cursor` ➔ `Set Cursor Speed (900)` ➔ `Set Show Mouse Cursor (true)` ➔ `Set Input Mode Game And UI`.
2. Inventory closed: `Disable Virtual Cursor` ➔ `Set Show Mouse Cursor (false)` ➔ `Set Input Mode Game Only`.

> 💡 Open `Levels/HowToUse` with a gamepad connected to try it.

# SF Upscaler Toolkit - Quickstart Example

A graphics menu with an upscaler selector.

---

1. Add the ini line from **Installation & Setup**.
2. On menu open: hide the DLSS / FSR options if `Is DLSS Supported` / `Is FSR Supported` return false.
3. On selection: `Set And Apply Upscaler Mode (Type, Mode)`.
4. Frame generation toggle (only with DLSS / FSR): `Set And Apply Frame Generation (x2)`.

> 💡 Open `Levels/HowToUse` in the plugin content: supported upscalers are printed on start.
